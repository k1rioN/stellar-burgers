# Stellar Burgers

Космическая бургерная — SPA-конструктор бургеров. Проектная работа Яндекс
Практикума (курс «Фронтенд-разработчик. Расширенный»), выполнена
самостоятельно.

## Что умеет

- Каталог ингредиентов по категориям и конструктор бургера: булка, начинки,
  удаление и перестановка начинок, подсчёт цены.
- Оформление заказа: модальное окно с номером заказа, после заказа конструктор
  очищается.
- Лента заказов и история заказов в профиле.
- Детали ингредиента и заказа открываются в модальном окне поверх страницы и
  работают по прямой ссылке как отдельная страница (`/ingredients/:id`,
  `/feed/:number`, `/profile/orders/:number`).
- Регистрация, вход, восстановление пароля, редактирование профиля.
- Защищённые маршруты: профиль — только для авторизованных, вход и
  регистрация — только для гостей.
- Обновление access-токена по refresh-токену.

## Стек

React 18, TypeScript, Redux Toolkit (`createSlice`, `createAsyncThunk`),
React Router 6, Webpack, Storybook, Jest, Cypress, ESLint, Prettier.

## Тесты

- **Jest** — редьюсеры: слайсы конструктора и ингредиентов, корневой редьюсер.
- **Cypress** — e2e-сценарии страницы конструктора: добавление булки и начинок,
  модальное окно ингредиента (закрытие по крестику и оверлею), оформление заказа
  с номером и очисткой конструктора. Запросы к API подменяются фикстурами.

## Запуск

```bash
npm install
cp .env.example .env   # адрес API
npm start              # http://localhost:4000
```

Остальные команды:

```bash
npm test               # Jest
npm run cypress:open   # Cypress
npm run storybook      # Storybook на http://localhost:6006
npm run lint
```
